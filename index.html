Pengaturan

Masukkan kunci API Gemini dulu supaya Asta bisa menjawab. Kunci hanya disimpan di ponsel ini.
Buat gratis di aistudio.google.com/apikey. Kunci tersimpan hanya di browser ponsel ini dan tidak ikut terunggah ke mana pun selain ke Google saat Asta menjawab.
Kosongkan kalau tidak mau disapa dengan sebutan khusus.
Kalau muncul galat soal nama model, ganti dengan nama model terbaru dari AI Studio.
Sinkronisasi antar perangkat Catatan, ingatan percakapan, sebutan, dan mode disamakan di semua perangkat lewat Gist rahasia di akun GitHub-mu. Isinya dienkripsi dengan sandi di bawah sebelum dikirim, jadi tidak terbaca siapa pun, termasuk GitHub. Kunci API Gemini tidak ikut disinkronkan. Buat token (hanya centang gist), lalu salin dan tempel di sini. Karang sandi ini sendiri. Pakai sandi yang persis sama di setiap perangkat. Kalau lupa, data yang sudah tersinkron tidak bisa dibuka lagi. Menghapus data sinkron di GitHub (bukan catatan di perangkat ini). Pakai ini kalau lupa sandi atau salah membuat sandi.
Di paket gratis Gemini, pesan dan lampiranmu bisa dipakai Google untuk meningkatkan produknya. Hindari mengirim dokumen pribadi atau identitas.
